Backend playback, CTC workflow, smarter FX and a cleaner GUI bootstrap.

This release groups the biggest local changes since the last Git snapshot: cue-list playback is now backend-driven, the GUI startup is more robust, intelligent effects can be described in JSON for both JS and Python, and the settings/UI workflow has been reorganized around show operation.

Smoother playback Faster cue building Cleaner desktop app

CTC grew into a real timing tool

CTC is now meant to capture show timing, not just append blank cues.

  • Dedicated settings, keybind capture and visible runtime indicator.
  • Optional capture-on-release mode for press/release timing workflows.
  • Split reset logic tied to cue starts, fade ends and cue captures.
  • Continues after cue-list playback until you explicitly stop it.

Playback engine overhaul

Long cue lists now rely on a Python-owned timeline instead of chained browser timers.

  • Backend cue-list scheduler with pause, skip, wait adjust and play-from support.
  • Playback clock modes for normal timeline mode and host absolute clock mode.
  • Playback speed presets that affect both the cue timeline and intelligent effects.
  • Backend-side profiling and throttled UI refresh for smoother long runs.

UI and GUI quality pass

The operator-facing workflow is more structured and the desktop wrapper behaves better.

  • Playback controls moved into the cue-list panel and grouped by function.
  • Advanced settings toggle with a simpler default settings view.
  • Custom GUI-safe modals instead of fragile popup fallbacks.
  • Desktop startup splash, delayed handoff, cache-busted reload and better popup reintegration.

Intelligent effects import is no longer UI-only

Declarative effect files can now be imported once and executed by both runtimes.

  • New shared JSON effect format for backend-compatible imports.
  • Runtime interpreter in JS and Python for importable intelligent effects.
  • Haut/Bas migrated to the new format and corrected as a true high/low pulse effect.

Other notable changes

Under the hood, playback timing and desktop startup have also been tightened up so the app feels more stable during long sessions.

  • Settings footer now exposes version and license code.
  • Playback status, speed display and cue highlighting are driven more cleanly from backend state.
  • Multi-selection cue moves behave more consistently across buttons and drag actions.
